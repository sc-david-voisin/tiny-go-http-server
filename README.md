# tiny-go-http-server

Fast and easy to deploy app on Scalingo stacks, minimal ones included.

It also display the stack at startup.
Example:

```
26-08-24 18:05:06.844616043 +0200 CEST[web-1] 2026/08/24 16:05:06 Stack "scalingo-24", listening on port 21865
...
2026-08-25 11:49:49.868274288 +0200 CEST[web-1] 2026/08/25 09:49:49 Stack "scalingo-26-minimal", listening on port 21904 
```
